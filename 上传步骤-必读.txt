【这是一封带口令锁的信 —— 上传步骤】

一、这个包里有什么
────────────────────────
· 99 个文件，全部平铺在同一层，没有子文件夹 —— 上传时不需要建目录，也不能建目录。
· index.html = 封蜡锁页（别人点链接第一眼看到的就是它）
· card.html  = 贺卡本体（口令验证通过后才会进到这里）
· 打开后的流程：点一下拆掉火漆 → 再点一下信封打开、卡片升起 → 再点翻开读信
· loader-flake.webp = 加载页那颗大雪花
· bgm.mp3       = 背景音乐（Nils Frahm《Ambre》，已做成首尾交叉淡化的无缝循环，24.6 秒一循环）
· 其余是页面、图片、字体。名字不用管，原样上传即可。

※ 音乐怎么响：第一次点「拆火漆」就会淡入播放，循环。右下角喇叭按钮可静音。
  手机（微信/iOS）不允许网页自己出声，必须由这一下点击唤醒 —— 这是正常的。
  想换成完整版或别的歌：把一个 mp3 改名成 bgm.mp3 覆盖即可，路径和名字都别改；
  换长曲子时告诉我，我按同样方法给你切一段无缝循环。

二、口令
────────────────────────
口令：1229    （她的生日，12 月 29 日）
想换成别的：告诉 AI 一声，一分钟重打一个包。页面里没有"改口令"的地方，改口令只能重新打包。

三、上传（手机 / 电脑都能做）
────────────────────────
1. 打开 https://github.com/yv-Special/Mysterious-gift
2. 页面中下方蓝色 Quick setup 框里，点 "uploading an existing file"
   （或右上 Add file → Upload files）
3. 把本文件夹里的全部文件选进去
   · 电脑：直接把整个文件夹拖到虚线框里，10 秒搞定
   · 手机：解压后用「文件」App 打开文件夹 → 全选 → 上传
     手机多选会比较累，强烈建议借一台电脑做这一步
4. 下方 Commit changes 点一下，等进度条走完

四、开 Pages（只做一次）
（若之前已经开过并拿到链接，跳过本节）
────────────────────────
5. 仓库顶部 Settings → 左侧栏 Pages
6. Build and deployment 区：Source 选 "Deploy from a branch"
7. Branch 选 main，右边目录选 "/ (root)" → Save
8. 等 1–2 分钟，回到 Settings → Pages，顶部会出现
   "Your site is live at https://yv-special.github.io/Mysterious-gift/"

五、发给对方
────────────────────────
先自己手机打开链接确认：出现封蜡页 → 输入 1229 → 拆信封 → 翻开读信。
正常后，把「链接 + 口令 1229」一起发过去。

六、对方第二次打开
────────────────────────
同一个人在同一个浏览器里，输过一次就不用再输 —— 锁页会自动放行进 card.html。
换手机、换浏览器、清过浏览器数据，就要重新输一次。

七、常见问题
────────────────────────
· 打开是 404：确认 index.html 在仓库根目录、分支是 main、再等 5 分钟。
  仍不行，去仓库 Actions 页看最近一次 pages build 的报错。
· 打开是白页 / 一直在转：多半是文件没传全（漏了某个 .webp 或 .js）。
  对比仓库根目录的文件数量和本包是否一致。
· 直接访问 card.html 会被踢回锁页，这是正常的（防止绕过口令）。
· 想把锁拆掉、让它彻底公开：告诉 AI，给你一个去掉 guard 的版本。

五、想先在电脑上看一眼（可选）
────────────────────────
这张贺卡是本地网页，不能直接双击 index.html 打开（浏览器会拦本地文件）。
1. 打开终端，进入本文件夹
2. 运行：python3 -m http.server 8000 --bind 127.0.0.1
3. 浏览器访问 http://127.0.0.1:8000/ ，输入口令 1229
4. 看完在终端按 Ctrl+C 停止
所有文件都在同一层，不需要 art/、vendor/ 之类的子目录。

六、这一版改了什么
────────────────────────
· 加载页：卡片封面换成一整屏雪花，转着"装帧"
· 封口信封：去掉封盖边缘那道黑线，只留很淡的接触阴影
· 抽卡：信封上沿那条纸边挪到卡片后面，卡片不再被横切一刀
· 音乐：Nils Frahm《Ambre》，24.6 秒无缝循环，点拆火漆时淡入
